## [1.0.0] - 2026-10-26

### Added

- First public release: an Ollama client for summarisation, grammar-constrained JSON extraction
  and closed-question decisions with log-probability confidence, published from the `nuvek-core`
  repository under the MIT licence. The endpoint and model names come from the caller's
  `LlmConfig`.
